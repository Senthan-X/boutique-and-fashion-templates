SENTHAN & CO — BOUTIQUE & FASHION REPOSITORY NOTES

Repository: Senthan-X/boutique-and-fashion-templates
Default branch: main

The repository contains the collection landing page and eight standalone storefront demos. Each demo is a self-contained HTML file with embedded imagery and inline CSS and JavaScript.

PUBLISHING

The GitHub Actions workflow at .github/workflows/pages.yml publishes the repository root to GitHub Pages when a commit is pushed to main. It can also be run manually from the Actions tab. Do not upload a ZIP as the Pages source.

CURRENT DEMO FILES

- index.html
- resole.html
- maisonrue.html
- baleyard.html
- streetfixco.html
- secondthread.html
- maison-index.html
- atelier-index.html
- eclat-index.html

The collection supports English, Spanish, French, German, Portuguese, Arabic with RTL, Chinese, and Swahili. Demo contact information is fictional sample data located in East Africa.
